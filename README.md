# VideoText

Version 0.1

## Project Goal

Extract visible text from a local video and export it to an Excel spreadsheet.

---

## Version 0.1 Scope

- Read a local video file
- Extract one frame every second
- Perform OCR using PaddleOCR
- Export results to Excel

Items outside this scope are placed in the Parking Lot.

---

## Parking Lot

- AI Vision OCR
- Scene detection
- Duplicate text removal
- Translation
- URL support
- Improved GUI
